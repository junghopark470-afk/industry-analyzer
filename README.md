# 산업동향 분석기

주식 투자를 위한 산업별 체크 보드. GitHub Pages로 배포됩니다.

- `index.html`: 홈 (산업 선택)
- `shipbuilding/index.html`: 조선업 산업 리포트
- `shipbuilding/stocks.html`: 조선 3사 주가 비교
- `assets/`: 공용 차트(`charts.js`), 공용 메뉴 스타일(`site.css`)

새 산업은 `<산업>/` 폴더를 추가하고 상단 탭 목록에 등록하면 됩니다.

개인 투자 참고용 자료이며 투자 권유가 아닙니다.

## 데이터 기준

- 주가: Yahoo Finance 공식 종가(일별 2025-05-02~, 월별 2021-09~), 코스피는 ^KS11 지수. 최종 반영 2026-11-24 종가.
- 수주·선가·실적·정책: 리포트 하단 출처 목록 참고.
